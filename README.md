Gestor de Inventario para Pequeño Negocio
Descripción del proyecto
Este proyecto consiste en el desarrollo de una aplicación web/móvil diseñada para ayudar a pequeños negocios a gestionar su inventario de manera eficiente. La aplicación permitirá a los administradores registrar, actualizar y controlar el stock de productos, mientras que los empleados podrán consultar la disponibilidad de productos y registrar ventas en tiempo real. El objetivo principal es digitalizar y simplificar un proceso que en muchos negocios pequeños todavía se realiza de forma manual o mediante hojas de cálculo poco integradas.
Exposición del problema
Muchos pequeños negocios administran su inventario utilizando métodos manuales, como cuadernos físicos o archivos de Excel desconectados entre sí. Esta práctica genera varios problemas recurrentes:

-	Falta de actualización en tiempo real del stock disponible.
-	Errores humanos al registrar ventas o movimientos de inventario.
-	Dificultad para identificar productos con bajo stock antes de que se agoten.
-	Pérdida de tiempo al buscar información dispersa en distintos archivos.
-	Ausencia de reportes claros que permitan tomar decisiones informadas sobre compras o precios.

Estos problemas afectan directamente la rentabilidad y la capacidad de respuesta del negocio frente a la demanda de sus clientes. La aplicación propuesta busca resolver estas dificultades centralizando la información del inventario en una sola plataforma accesible y fácil de usar.

Interfaz de usuario e interfaz de administrador
Interfaz de usuario (empleado)
Los empleados tendrán acceso a una interfaz simplificada que les permitirá:

-	Buscar productos por nombre o categoría.
-	Consultar la cantidad disponible en stock.
-	Registrar una venta, lo cual actualizará automáticamente el inventario.
-	Ver un historial básico de las ventas realizadas durante su turno.
Interfaz de administrador
El administrador contará con una interfaz más completa que incluirá:

-	Agregar, editar o eliminar productos del catálogo.
-	Actualizar precios y cantidades de stock manualmente.
-	Visualizar reportes de ventas por período (diario, semanal, mensual).
-	Recibir alertas cuando un producto esté por debajo del nivel mínimo de stock.
-	Gestionar los usuarios del sistema (empleados con acceso a la aplicación).
Funcionalidad
Las funcionalidades principales del sistema incluyen:

1.	Registro de productos: permite ingresar nombre, categoría, precio, cantidad y proveedor de cada producto.
2.	Control de stock en tiempo real: cada venta o ingreso de mercancía actualiza automáticamente las cantidades disponibles.
3.	Registro de ventas: los empleados pueden generar una venta seleccionando productos y cantidades, y el sistema descuenta el stock correspondiente.
4.	Alertas de inventario bajo: el sistema notifica al administrador cuando un producto alcanza un nivel crítico de stock.
5.	Reportes: generación de reportes de ventas y de inventario que ayudan al administrador a tomar decisiones.
6.	Gestión de usuarios: el administrador puede crear cuentas para los empleados y definir sus permisos de acceso.
